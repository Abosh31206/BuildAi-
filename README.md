# BuildAI KZ — Онлайн-платформа строительных калькуляторов Казахстана

Профессиональная онлайн-платформа инженерных строительных калькуляторов, разработанная для строительной отрасли Республики Казахстан (инженеры ПТО, сметчики, проектировщики, студенты строительных вузов и подрядные компании).

## 🚀 Возможности платформы

- **5 специализированных калькуляторов первой версии (MVP):**
  1. **Калькулятор бетона** — расчёт объёма по формуле $V = L \times B \times H$ с учётом технологического процента запаса, ориентировочной массы и мешков цемента.
  2. **Калькулятор арматуры** — точный расчёт теоретической массы погонного метра по инженерной формуле $m = d^2 / 162$ по ГОСТ 34028 / ГОСТ 5781, общий метраж и тоннаж стержней.
  3. **Калькулятор фундамента** — объём бетона, площадь подошвы основания $S = L \times B$, боковая опалубка и расчёт с учётом запаса.
  4. **Земляные работы** — расчёт выемки в плотном теле $V = L \times B \times H$ и объёма после разрыхления по персональному коэффициенту $k_р$ (песок, супесь, суглинок, глина, скальные грунты).
  5. **Кирпичная кладка** — чистая площадь стен за вычетом проёмов, объём кладки, количество кирпича (одинарный 1.0НФ, полуторный 1.4НФ, двойной 2.1НФ или произвольный размер), толщина швов и объём кладочного раствора.

- **Двуязычный интерфейс (RU / KZ):**
  - Русский язык;
  - Қазақ тілі.
  - Мгновенное переключение без перезагрузки страницы с сохранением в `localStorage`.

- **Инженерный функционал:**
  - Наглядное отображение математических формул и подстановки значений;
  - Проверка корректности введённых данных (валидация);
  - Локальная история расчётов (`localStorage`) с возможностью быстрого восстановления параметров в калькулятор;
  - Функция печати и подготовки официального бланка расчёта для сохранения в **PDF** через браузер;
  - Привязка к нормативной базе Республики Казахстан (СП РК, СН РК, ГОСТ).

## 🛠 Стек технологий

- **Фреймворк:** React 19 + TypeScript
- **Сборщик:** Vite
- **Стилизация:** Tailwind CSS v4
- **Иконки:** Lucide React
- **Шрифты:** Plus Jakarta Sans & JetBrains Mono

## 💻 Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```

Приложение откроется по адресу `http://localhost:3000`.

## 📦 Сборка и деплой на Vercel / GitHub

### 1. Подготовка к загрузке на GitHub
```bash
git init
git add .
git commit -m "feat: initial commit BuildAI KZ MVP platform"
git branch -M main
git remote add origin https://github.com/<your-username>/buildai-kz.git
git push -u origin main
```

### 2. Деплой на Vercel
1. Перейдите на [vercel.com](https://vercel.com) и подключите ваш репозиторий GitHub.
2. Vercel автоматически определит Vite-проект:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
3. Нажмите **Deploy**. Проект опубликуется за несколько секунд.
